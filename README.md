A tiny program that writes exactly one line to `/output/entry.txt` — the
label a museum in the year 3000 puts beside a **rubber duck**: a bathroom
oracle, consulted before important decisions, whose squeaker announced
the verdicts. The line was drafted with an OpenCode free-model round,
then won a criteria-ordered tournament against the judge's published
criteria (a real label beside an ordinary object from today, the joke
landing on a first read, the humour in the future's misreading, straight-
faced label register, a fresh object and angle), beating the television
remote shrine and the sticky-note prayer flag. Output is byte-exact:
160 UTF-8 bytes, no trailing newline. Run it with `python3 main.py`.
